# 유행 감지·추적 조사 — 데이터 소스, 규칙, 실험 결과

문서 버전: 1.0 · 조사일: 2026-09-14 · 용도: F02(근거 수집)·F03(추출)·F04(후보 상태) 자동화(P1)의 설계 근거
상태: **조사와 소규모 실험 결과**다. 아래 규칙·파이프라인은 앱에 구현된 기능이 아니며, 실험은 2026-09-14 하루 스냅샷으로 수행했다.

## 0. 요약

- 유행 감지는 **발견(discovery)** 과 **추적(tracking)** 으로 나눈다. 발견은 아직 이름이 정착되지 않은 후보를 찾는 일, 추적은 이름이 잡힌 후보가 곡선의 어디(상승·정점·하락)에 있는지 재는 일이다. 사장님에게 보낼 타이밍은 추적에서 결정된다.
- 공식 API와 공개 페이지만 사용한다. 인스타그램·배달앱·커뮤니티 크롤링은 약관 위반 소지가 있어 제외한다.
- 실험으로 확인한 것: (1) 유행 이름을 전혀 주지 않고 도메인 씨앗어만으로 진행 중인 유행(피자설기)과 조사자가 몰랐던 후보(민음사빵 등)를 찾았다. (2) 일별 검색지수에 "7일 이동평균 7일 연속 상승" 규칙을 적용하면 두쫀쿠는 정점 23일 전에 감지됐고, 12일 만에 정점을 찍는 스파이크형(버터떡)은 감지일=정점일이라 사전 포착이 불가능했다. (3) 네이버 연령별 검색으로 유행마다 주 소비 연령이 다름을 확인했다(두쫀쿠=10대, 피자설기=30대).
- 되돌리기(과거 데이터로 재현) 검증은 API 특성상 근사치다. 실운영은 **매일 수집해 누적**하는 구조여야 한다.

### 1.1. 네이버 API 이관 주의 (2026-07-31 이후)

- 네이버 개발자센터(developers.naver.com)에서는 **검색·데이터랩 API 신규 신청이 중단**됐다. 개발자센터 애플리케이션 등록 화면의 "사용 API" 목록에 검색·데이터랩이 나오지 않는다.
- 신규 이용은 **네이버 클라우드 플랫폼(ncloud.com) → NAVER API HUB**에서 Application을 만들고 사용 API에 "Search Trend"와 "검색"을 체크해 구독해야 한다. Application 등록 후 API 구독을 추가하지 않으면 `401 {"errorCode":"210","message":"Permission Denied","details":"A subscription to the API is required."}` 가 반환된다.
- 인증 헤더는 `X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY`. 구 방식(`X-Naver-Client-Id/Secret`, `openapi.naver.com`)은 기존 신청자만 2027-06-30까지 한시 사용.
- 요청 본문(Search Trend): `startDate`, `endDate`(YYYY-MM-DD), `timeUnit`(`date`/`week`/`month`), `keywordGroups`(그룹당 `groupName`, `keywords[]`; 한 요청 최대 5그룹), 선택 `ages`(코드 배열), `gender`(`m`/`f`), `device`.
- 연령 코드(실험에서 사용): 1~2=10대, 3~4=20대, 5~6=30대, 7~8=40대, 9~10=50대, 11=60대 이상.
- 키는 `.env`에 보관하고 저장소에 올리지 않는다.

### 1.2. 네이버 검색지수의 정규화 문제와 기준자 방법

Search Trend는 **요청 단위로 최대값을 100으로 정규화**한다. 연령별로 따로 요청하면 각 요청이 자기 최대값 기준이라 연령 간 크기를 비교할 수 없다. 실험에서는 같은 요청에 기준자 키워드 그룹("날씨")을 함께 넣고, `후보 지수 합 ÷ 기준자 지수 합`을 그 연령대의 상대 관심도로 썼다. 이 값은 "그 연령대의 평소 검색 활동 대비 관심도"이며 절대 검색량이 아니다. 기준자는 계절·사건에 따라 흔들릴 수 있으므로 문서에 기준자 이름을 함께 기록한다.

## 2. 파이프라인 (설계안)

```
① 씨앗 수집 (매일)
   도메인 씨앗어만 사용: 디저트, 신메뉴, 편의점 신상, 카페 신상, 빵집, 떡집, 간식, 요즘 유행, 베이커리 신상, 카페 디저트
   - 네이버 블로그 최신순 글 (씨앗어당 최대 1000건)
   - Google Trends 급상승 연관어 (씨앗어당, 30일 창)
   - 편의점 신상품명 diff, TikTok 급상승 해시태그
        ↓
② 후보 추출 (n-gram 버스트)
   텍스트를 2~5글자 한글 조각(n-gram)으로 자른다. 사전 없음.
   조각별 출현율(문서 수 ÷ 코퍼스 문서 수)을 최근 코퍼스와 기준 코퍼스에서 계산해 비율을 점수로 쓴다.
   조사·어미·범용어(습니다, 어요, 추천, 후기, 맛집, 디저트 …)는 제외 목록으로 거른다.
   부분 문자열 가족(피자설/자설기/피자설기)은 가장 긴 조각으로 묶는다.
        ↓
③ LLM 필터·정규화 (= 상세기획서 F03)
   음식인가 / 신메뉴인가 / 브랜드 정규 출시·콜라보·연예인·계절·게임인가 분류
   별칭 통합(두쫀쿠 = 두바이 쫀득 쿠키), 재료·형태 추출
   교차 확인: 두 소스 이상에서 나온 후보는 확정, 하나만 나온 후보는 보류
        ↓
④ 추적 (후보별 매일)
   네이버 Search Trend 일별 지수(전체 + 연령별 기준자 방식) + 블로그 신규 글 수 + (선택) 유튜브 조회 증가
        ↓
⑤ 단계 판정 → 사장님에게는 "상승" 단계 후보만, 연령 프로파일과 함께
```

②의 "기준 코퍼스"는 실운영에서는 **이전 4주 누적 수집분**이다. 되돌리기 실험에서는 같은 씨앗어의 관련도순(`sort=sim`) 검색 결과(오래된 글 위주)로 대체했으며, 이는 근사치다.

## 3. 단계 판정 규칙 (실험으로 튜닝한 값)

일별 검색지수 `s`, 7일 이동평균 `m7` 기준.

| 단계 | 조건 | 비고 |
|---|---|---|
| 감지 | `m7`이 **7일 연속 상승**하고 `m7 ≥ 10` | 처음엔 14일 연속으로 잡았으나 두바이초콜릿(계단식 상승)을 놓치고 피자설기는 정점 뒤에 잡혀, 7일로 조정 |
| 상승 | 감지 후 정점 미확인 | **사장님 알림은 이 단계에서만** |
| 정점 | `m7`이 하락 전환 | |
| 하락 경고 | `m7 ≤ 정점의 50%` | "지금 들어가면 끝물" |
| 종료 | `m7 ≤ 정점의 30%` | 기사(두쫀쿠 49일)와 같은 기준 |
| 부적합 필터 | 감지 후 상승이 7일 미만에 정점 도달 | 스파이크형(버터떡). 재료 구매 전 끝나므로 훅 후보에서 제외 |

훅 창(사장님이 움직일 수 있는 기간)은 **감지일 → 정점의 50% 하락일**로 정의한다.

- 블로그에 없던 후보: 개성 주악, 몽블랑 디저트, 알통 떡강정, 솔티 조청 뉴욕치즈케이크, 투썸 고구마 케이크.
- 잡음의 형태: 쿠키런(게임), 오크 스트리트(드라마), 제3자 쿠키(웹), 추석 간식(계절). 씨앗 "편의점 신상", "카페 신메뉴"는 검색량이 적어 연관어가 없었다.

결론: 유행 이름 없이 두 독립 소스가 같은 후보(피자설기, 민음사빵)를 상위에 올렸다. 12개 중 6개가 음식이므로 ③ LLM 필터는 필수이고, 교차 확인을 확정 조건으로 쓰면 정밀도가 오른다. n-gram은 유행 이름뿐 아니라 재료·구성(페퍼로니, 토마토소스, 책갈피)도 띄우므로 F06 재료 매칭의 입력으로 재활용할 수 있다.

### 4.4. 되돌리기 검증의 한계

- 네이버 블로그 API는 날짜 필터가 없고 `sort=date`로 최신 1,000건만 준다. 씨앗어마다 커버 기간이 달라("설기"는 최근 4일, "떡 신메뉴"는 4개월) 과거 시점의 버스트 순위가 샘플 편향에 흔들렸다. 씨앗어 "설기"로 되돌린 실험에서 피자설기 7일 문서 수는 8/29 2건 → 9/2 47건 → 9/6 123건으로 늘었지만 순위표는 편향으로 신뢰할 수 없었다.
- 따라서 발견 층의 정량 평가는 실운영(일별 누적)에서만 가능하다. 본 문서의 발견 실험은 "이름 없이 찾을 수 있는가"에 대한 정성 확인이다.

```python
import json, urllib.request
H={"X-NCP-APIGW-API-KEY-ID":KEY_ID,"X-NCP-APIGW-API-KEY":KEY,"Content-Type":"application/json"}
body={"startDate":"2026-08-20","endDate":"2026-09-14","timeUnit":"date",
      "keywordGroups":[{"groupName":"후보","keywords":["피자설기","피자 설기"]},
                       {"groupName":"anchor","keywords":["날씨"]}],
      "ages":["5","6"]}   # 30대
req=urllib.request.Request("https://naverapihub.apigw.ntruss.com/search-trend/v1/search",
                           data=json.dumps(body).encode(),headers=H,method="POST")
r=json.loads(urllib.request.urlopen(req).read())
p=sum(d["ratio"] for d in r["results"][0]["data"]); a=sum(d["ratio"] for d in r["results"][1]["data"])

```
