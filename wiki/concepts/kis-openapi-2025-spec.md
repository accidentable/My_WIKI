## 한 줄 정의

2025년 이후 한투 OpenAPI의 주문 TR 코드·필수 파라미터·호가단위가 바뀌어서,
예전 코드를 그대로 쓰면 주문이 거부된다.

## 어디서 썼는가

- [[kis-openapi-invest-2026-09]] — `core/kis/` 전체

## 실제로 겪은 문제와 해결

### TR 코드 변경

| 기능 | 구버전 | 현재 |
|---|---|---|
| 매수 | `TTTC0802U` | `TTTC0012U` |
| 매도 | `TTTC0801U` | `TTTC0011U` |
| 정정/취소 | `TTTC0803U` | `TTTC0013U` |
| 미체결 조회 | `TTTC8036R` | `TTTC0084R` |

### 주문 body 필수 필드

NXT 대체거래소 출범으로 `EXCG_ID_DVSN_CD`가 필수로 추가됐다.
`KRX` / `NXT` / `SOR`(최선주문집행) 중 선택하며 기본값은 `KRX`.

### 호가단위

2023-01-25 개편으로 코스피·코스닥이 통일됐다. 지정가가 호가에 안 맞으면 주문이 거부되므로
모든 지정가를 보정 함수(`core/kis/tick.py`)에 통과시킨다.

| 가격 | 호가단위 | | 가격 | 호가단위 |
|---|---|---|---|---|
| ~2,000 | 1 | | 50,000~200,000 | 100 |
| 2,000~5,000 | 5 | | 200,000~500,000 | 500 |
| 5,000~20,000 | 10 | | 500,000~ | 1,000 |
| 20,000~50,000 | 50 | | | |

### 토큰과 유량제한

- 접근토큰은 24시간 유효하고 재발급은 1분에 1회로 제한된다. 람다처럼 인스턴스가 여럿이면
  각자 발급하다 제한에 걸리므로 SSM 등으로 캐시를 공유해야 한다.
- 유량제한은 실전 계좌 기준 조회 초당 20건, 주문 초당 1건.
  위 프로젝트는 `KIS_RATE_LIMIT_PER_SEC` 기본값을 8로 두어 여유를 뒀다.
- 매수 수량은 **미수없는매수수량**을 기준으로 잡는다. 미수(증거금 대출)를 쓰면
  반대매매 위험이 생기고 대회 수익률 계산이 꼬인다.
